# CalculadoraANTLR

Calculadora cientifica desarrollada en Java utilizando ANTLR y el patron Visitor.

## Funcionalidades

- Operaciones basicas
- Variables
- Potencias
- Funciones matematicas
- Constantes pi y e
- Comandos clear y vars
- Graficacion de funciones

## Tecnologias

- Java
- ANTLR 4
- Java Swing

## Archivos principales

- `ScientificCalc.g4`: define la gramatica.
- `ScientificEvalVisitor.java`: implementa la evaluacion.
- `Main.java`: inicia el Lexer, Parser y Visitor.
- `PlotWindow.java`: dibuja las funciones.
- `ejemplos.txt`: contiene pruebas del lenguaje.
